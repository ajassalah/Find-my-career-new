# Find My Career - Website Redesign

This is the source code for the "Find My Career" website redesign.

## How to Run

1.  **Install Node.js**: Ensure you have [Node.js](https://nodejs.org/) installed on your computer.
2.  **Open Terminal**: Open a command prompt or terminal in this folder.
3.  **Install Dependencies**: Run the following command to download the necessary libraries (this creates the `node_modules` folder):
    ```bash
    npm install
    ```
4.  **Start the Server**: Run the following command to start the website locally:
    ```bash
    npm run dev
    ```
5.  **View Website**: Hold `Ctrl` and click the URL shown in the terminal (usually `http://localhost:5173` or `http://localhost:5174`), or copy and paste it into your browser.

## Project Structure

*   `*.html`: The main pages of the website.
*   `style.css`: The main stylesheet containing the Neo-brutalist design.
*   `main.js`: Main JavaScript entry point (Vite).
*   `public/`: Static assets.

## Notes for Reviewer

*   The design uses a "Neo-brutalist" style with bold borders, shadows, and vibrant colors.
*   Navigation is consistent across all pages.
*   The "Free Consultation" buttons link to the functional `book-consultation.html` page.
